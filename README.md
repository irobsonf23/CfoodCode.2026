🏢 Sistema de Consulta de Moradores

Um miniaplicativo desenvolvido para facilitar a consulta de informações dos moradores de um condomínio.

📱 Funcionalidades
👤 Cadastro do nome do morador
🏠 Identificação do número do apartamento
🍔 Armazenamento do código do pedido/código do iFood
🔍 Barra de pesquisa por nome do morador
🔎 Pesquisa pelo número do apartamento
⚡ Consulta rápida das informações cadastradas
🛠️ Tecnologias utilizadas
HTML
CSS
JavaScript
🎯 Objetivo

O objetivo deste projeto é facilitar a localização das informações dos moradores através de uma pesquisa simples e rápida pelo nome ou número do apartamento.

🔍 Como utilizar
Abra o aplicativo.
Digite o nome do morador ou o número do apartamento na barra de pesquisa.
Localize o morador desejado.
Visualize o código cadastrado.
